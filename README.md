# Student Management System

A simple React application demonstrating component rendering.

## Features
- Displays roll number, student name, percentage, total marks, and grade.
- Adds new student records.
- Calculates percentage and grade automatically.
- Uses reusable `StudentRow` and `StudentTable` components.
- Responsive layout with a header and footer.

## Run locally
1. Install Node.js (LTS).
2. Open this project folder in VS Code.
3. Open the terminal and run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal (usually http://localhost:5173).

## Grade scale
A+ 90–100, A 80–89, B 70–79, C 60–69, D 50–59, F below 50.
